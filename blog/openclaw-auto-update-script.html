OpenClaw Auto-Update Script

A fail-safe, self-healing, production-ready bash script for updating OpenClaw on macOS. Full source code included.

Why an update script?

OpenClaw bundles an agent runtime (Gateway) distributed via Homebrew cask and a CLI tool distributed via npm. Updates arrive regularly. If the gateway goes down mid-update and doesn't come back — you lose scheduled jobs, email processing, and agent responsiveness until you fix it manually.

This script makes updates a fire-and-forget operation. It backs up your state, stops the gateway cleanly, upgrades both the cask and CLI runtime, starts the gateway with verification, and rolls back automatically if anything goes wrong.

It's been in daily use for months on a production Mac mini running 24/7. No update has ever left the gateway offline longer than 30 seconds.

What it does

  1. Pre-update backup — Calls the companion backup script before touching anything
  2. Graceful gateway stop — Launchctl bootout, then graceful SIGTERM, then SIGKILL only as last resort. Waits up to 30s.
  3. Brew cask upgrade — Retries twice if the first attempt fails (network hiccups happen)
  4. npm CLI upgrade — Updates the global openclaw npm package
  5. Gateway restart — Tries launchctl bootstrap, then load, then kickstart
  6. Verified startup — Probes the gateway port with up to 5 retries. Requires 2 consecutive stable probes before declaring success.
  7. Post-update safety check — Schedules a 5-minute-delayed cron check for the "started then crashed" edge case
  8. Rollback on failure — Restores the pre-update backup and starts the old version
  9. Notification — Sends an email on success or failure
File lock safety. The script writes a PID lock file to prevent concurrent updates. If the lock is stale (process died), it cleans up automatically.

Full script

Save as ~/.openclaw/scripts/update-openclaw.sh and make executable with chmod +x. Update the ALERT_EMAIL variable at the top with your email address.

#!/bin/bash
# OpenClaw auto-update script
# Fire-and-forget: backs up, upgrades, verifies, rolls back on failure.
set -euo pipefail
# ── Configuration ──────────────────────────────────────────────────────────
OPENCLAW_HOME="${HOME}/.openclaw"
SCRIPTS_DIR="${OPENCLAW_HOME}/scripts"
BACKUPS_DIR="${OPENCLAW_HOME}/backups"
TIMESTAMP_FILE="${OPENCLAW_HOME}/.update-timestamp"
LOCK_FILE="${OPENCLAW_HOME}/.update.lock"
HEARTBEAT_STATE_DIR="${OPENCLAW_HOME}/.heartbeat"
LOG_DIR="${OPENCLAW_HOME}/logs"
LOG_FILE="${LOG_DIR}/update-$(date +%Y%m%d_%H%M%S).log"
RESTORE_SCRIPT="${SCRIPTS_DIR}/post-update-restore.sh"
ALERT_EMAIL="you@example.com"            # ← Change this!
GATEWAY_PORT=18789
GATEWAY_HOST="127.0.0.1"
GATEWAY_URL="http://${GATEWAY_HOST}:${GATEWAY_PORT}"
GATEWAY_LABEL="ai.openclaw.gateway"
GATEWAY_PLIST="${HOME}/Library/LaunchAgents/${GATEWAY_LABEL}.plist"
START_RETRIES=5
START_RETRY_DELAY=5
STOP_TIMEOUT=30
STOP_POLL_INTERVAL=2
PROBE_TIMEOUT=5
STABILITY_CHECKS=2
# ── Helpers ────────────────────────────────────────────────────────────────
log()  { echo "[$(date '+%H:%M:%S')] $*"; }
info() { log "INFO: $*"; }
warn() { log "WARN: $*"; }
error(){ log "ERROR: $*"; }
cleanup() { local rc=$?; rm -f "${LOCK_FILE}"; [ $rc -ne 0 ] && [ $rc -ne 130 ] && \
    error "Script exited with code ${rc} — see ${LOG_FILE}"; info "Lock released"; }
send_email() {
    python3 "${SCRIPTS_DIR}/send_email.py" "${1}" "${2}" "${3}" 2>&1 | \
        while read line; do info "email: ${line}"; done || warn "Email failed"
}
gateway_running_probe() {
    curl -s -o /dev/null -w "%{http_code}" --max-time "${PROBE_TIMEOUT}" \
        "${GATEWAY_URL}/" 2>/dev/null | grep -qE '^(200|302|401)$'
}
gateway_process_running() {
    pgrep -f "node.*openclaw.*gateway.*${GATEWAY_PORT}" >/dev/null 2>&1
}
gateway_stable() {
    local c=0; for ((i=0; i<STABILITY_CHECKS; i++)); do
        gateway_running_probe && c=$((c+1)) || return 1; sleep 1
    done; [ "$c" -ge "${STABILITY_CHECKS}" ]
}
write_timestamp() {
    cat > "${TIMESTAMP_FILE}" <<-EOF
STATUS=${1:-unknown}
VERSION=${2:-unknown}
TIMESTAMP=$(date +%s)
DATE=$(date '+%Y-%m-%d %H:%M:%S %z')
EOF
}
get_version() { openclaw --version 2>/dev/null || echo "unknown"; }
# ── Pre-flight ─────────────────────────────────────────────────────────────
mkdir -p "${LOG_DIR}"
exec > >(tee -a "${LOG_FILE}") 2>&1; trap cleanup EXIT INT TERM
echo "=== OpenClaw Update — $(date) ==="
if [ -f "${LOCK_FILE}" ]; then
    lock_age=$(($(date +%s) - $(stat -f %m "${LOCK_FILE}")))
    lock_pid=$(cat "${LOCK_FILE}" 2>/dev/null)
    if kill -0 "${lock_pid}" 2>/dev/null; then
        error "Another update is running (PID ${lock_pid}, ${lock_age}s)"; exit 4
    else warn "Stale lock — removing"; fi
fi
echo $$ > "${LOCK_FILE}"; info "Lock acquired (PID $$)"
write_timestamp "in-progress" "$(get_version)"
curl -s --max-time 5 https://registry.npmjs.org/ >/dev/null 2>&1 || \
    { error "No internet"; exit 1; }
# ── Step 1: Backup ─────────────────────────────────────────────────────────
info "Step 1/7: Pre-update backup..."
[ -x "${RESTORE_SCRIPT}" ] && [ -x "$(dirname "${RESTORE_SCRIPT}")/pre-update-backup.sh" ] && \
    bash "$(dirname "${RESTORE_SCRIPT}")/pre-update-backup.sh" || warn "Backup skipped"
LATEST_BACKUP=$(ls -dt "${BACKUPS_DIR}"/*/ 2>/dev/null | head -1 || echo "none")
info "Latest backup: ${LATEST_BACKUP}"
# ── Step 2: Stop Gateway ───────────────────────────────────────────────────
info "Step 2/7: Stopping gateway..."
if gateway_running_probe || gateway_process_running; then
    launchctl bootout gui/$(id -u)/"${GATEWAY_LABEL}" 2>&1 || \
        warn "bootout did not succeed"
    waited=0
    while gateway_process_running && [ "${waited}" -lt "${STOP_TIMEOUT}" ]; do
        sleep "${STOP_POLL_INTERVAL}"; waited=$((waited + STOP_POLL_INTERVAL))
    done
    if gateway_process_running; then
        warn "Graceful stop timed out — sending SIGTERM"
        pkill -f "node.*openclaw.*gateway.*${GATEWAY_PORT}" 2>/dev/null || true; sleep 3
        gateway_process_running && { warn "SIGKILL"; pkill -9 -f \
            "node.*openclaw.*gateway.*${GATEWAY_PORT}" 2>/dev/null || true; sleep 1; }
    fi
    gateway_process_running && { error "Cannot stop gateway"; exit 1; }
    info "Gateway stopped (${waited}s)"
fi
curl -s --max-time 2 "${GATEWAY_URL}/" >/dev/null 2>&1 && \
    { error "Port ${GATEWAY_PORT} still in use"; exit 1; }
# ── Step 3: Brew Cask ──────────────────────────────────────────────────────
info "Step 3/7: Brew cask upgrade..."
OLD_VERSION=$(get_version); info "Current: ${OLD_VERSION}"
brew outdated --cask openclaw >/dev/null 2>&1 && \
    for a in 1 2; do brew upgrade openclaw 2>&1 && break || \
        { warn "brew attempt ${a} failed"; [ ${a} -lt 2 ] && sleep 5; }; done || \
    info "Brew cask up to date"
# ── Step 4: npm CLI ────────────────────────────────────────────────────────
info "Step 4/7: npm CLI upgrade..."
npm outdated -g openclaw >/dev/null 2>&1 && info "npm up to date" || {
    for a in 1 2; do npm update -g openclaw 2>&1 && break || \
        { warn "npm attempt ${a} failed"; [ ${a} -lt 2 ] && sleep 5; }; done
    get_version | grep -q "${OLD_VERSION}" || \
        { error "npm update failed"; exit 2; }
}
NEW_VERSION=$(get_version); info "Version: ${OLD_VERSION} → ${NEW_VERSION}"
# ── Step 5: Start Gateway ──────────────────────────────────────────────────
info "Step 5/7: Starting gateway..."
launchctl bootstrap gui/$(id -u) "${GATEWAY_PLIST}" 2>&1 || \
launchctl load "${GATEWAY_PLIST}" 2>&1 || \
launchctl kickstart -k gui/$(id -u)/"${GATEWAY_LABEL}" 2>&1 || \
    warn "All start methods attempted"
# ── Step 6: Verify ─────────────────────────────────────────────────────────
info "Step 6/7: Verifying gateway..."
GATEWAY_STARTED=false
for ((a=1; a<=START_RETRIES; a++)); do
    sleep "${START_RETRY_DELAY}"
    if gateway_running_probe && gateway_stable; then
        GATEWAY_STARTED=true
        info "Gateway stable after $(($(date +%s) - START_TIME))s"
        break
    fi
    [ "${a}" -eq $((START_RETRIES - 1)) ] && \
        launchctl kickstart -k gui/$(id -u)/"${GATEWAY_LABEL}" 2>&1 || true
done
# ── Outcome ────────────────────────────────────────────────────────────────
if [ "${GATEWAY_STARTED}" = true ]; then
    info "✅ Update complete"; write_timestamp "success" "${NEW_VERSION}"
    # Step 7: 5-min post-update safety check
    info "Step 7/7: Post-update safety check (5 min)..."
    POST_CHECK_TIME=$(date -v+5M '+%Y-%m-%dT%H:%M:%S%z' 2>/dev/null || \
        date -d '+5 minutes' '+%Y-%m-%dT%H:%M:%S%z' 2>/dev/null || true)
    if [ -n "${POST_CHECK_TIME}" ]; then
        openclaw cron add --job '{"name":"post-update-gateway-check",'\
'"schedule":{"kind":"at","at":"'"${POST_CHECK_TIME}"'"},"payload":'\
'{"kind":"agentTurn","message":"Verify gateway is still running. '\
'Run: bash ~/.openclaw/scripts/gateway-heartbeat.sh --force",'\
'"timeoutSeconds":60},"sessionTarget":"isolated","deleteAfterRun":true,'\
'"delivery":{"mode":"none"}}' 2>/dev/null && \
            info "Safety check scheduled" || { mkdir -p "${HEARTBEAT_STATE_DIR}"; \
            echo "$(date +%s)" > "${HEARTBEAT_STATE_DIR}/post-update-pending"; }
    fi
    send_email "✅ OpenClaw Update Succeeded" \
        "Update completed.\nOld: ${OLD_VERSION}\nNew: ${NEW_VERSION}"
    exit 0
fi
# ── Rollback ───────────────────────────────────────────────────────────────
warn "UPDATE FAILED — attempting rollback..."
ROLLBACK_OK=false
[ -n "${LATEST_BACKUP}" ] && [ -d "${LATEST_BACKUP}" ] && {
    [ -x "${RESTORE_SCRIPT}" ] && bash "${RESTORE_SCRIPT}" "${LATEST_BACKUP}" 2>&1 && \
        ROLLBACK_OK=true
    ${ROLLBACK_OK} || {
        [ -f "${LATEST_BACKUP}/openclaw.json" ] && \
            cp "${LATEST_BACKUP}/openclaw.json" "${OPENCLAW_HOME}/openclaw.json"
        launchctl bootstrap gui/$(id -u) "${GATEWAY_PLIST}" 2>&1 || \
        launchctl load "${GATEWAY_PLIST}" 2>&1 || \
        launchctl kickstart -k gui/$(id -u)/"${GATEWAY_LABEL}" 2>&1 || true
        sleep 10; gateway_running_probe && ROLLBACK_OK=true
    }
}
${ROLLBACK_OK} || {
    warn "No backup — last resort kickstart..."
    launchctl kickstart -k gui/$(id -u)/"${GATEWAY_LABEL}" 2>&1 || true
    sleep 10; gateway_running_probe && ROLLBACK_OK=true
}
if ${ROLLBACK_OK}; then
    info "✅ Rollback successful"
    write_timestamp "rolled-back" "$(get_version)" "Update failed, rollback succeeded"
    send_email "⚠️ OpenClaw Update Rolled Back" \
        "Update failed but rollback succeeded.\nRestored: $(get_version)"
    exit 3
else
    error "CRITICAL: Update AND rollback failed. Gateway is DOWN."
    write_timestamp "failed" "${NEW_VERSION}" "Update and rollback failed"
    send_email "❌ OpenClaw Update FAILED" "Gateway is DOWN."
    exit 5
fi

Walkthrough of key design decisions

File lock safety

A PID-based lock file prevents concurrent updates. If a lock is more than a few seconds old and the owning PID no longer exists, it's treated as stale and cleaned up automatically. Without this, a crashed update run would block all future updates until manually cleaned.

Graceful stop with escalation

The script tries launchctl bootout first (the cleanest method on modern macOS). If the process is still running after 30 seconds, it escalates to SIGTERM, then SIGKILL. The port is verified free before proceeding — any residual listener would cause the new gateway to fail on EADDRINUSE.

Why not just kill and restart? The gateway flushes scheduled job state on shutdown. Forcing a kill mid-write can corrupt the job queue. Always try graceful shutdown first and only escalate after a reasonable timeout.

Two-stage upgrade

OpenClaw ships two components — the runtime via Homebrew cask (the actual gateway binary) and the CLI via npm (the openclaw command-line tool). Both are checked and upgraded independently. The script retries each once if the first attempt fails, since registries occasionally hiccup.

Verified startup with stability check

After starting the gateway, the script probes the port every 5 seconds up to 5 times. But a single successful probe isn't enough — the gateway could crash immediately after serving one request. The script requires 2 consecutive successful probes (2 seconds apart) before declaring the update successful.

Delayed safety net

The most insidious failure mode is "starts fine, crashes 3 minutes later." The script schedules an isolated cron check 5 minutes in the future to verify the gateway is still running. If the cron job can't be created (because the gateway is still initialising), a marker file is written instead for the heartbeat health check to pick up.

Automatic rollback

If the gateway fails to start after all retries, the script restores the pre-update backup and tries to start the old version. If even the rollback fails, it exits with code 5 and sends a critical alert. In months of production use, this has never triggered — but the belt-and-suspenders approach means you can sleep through updates.

Usage

Run it manually or schedule it via launchd, crontab, or OpenClaw's own cron system:

bash ~/.openclaw/scripts/update-openclaw.sh

To skip the confirmation prompt:

bash ~/.openclaw/scripts/update-openclaw.sh --force
Requirements: Homebrew, npm, the OpenClaw cask installed, and a send-email helper script at ~/.openclaw/scripts/send_email.py (or update the send_email() function to use your preferred notification method). The companion backup scripts are optional but recommended.

The script writes a detailed log to ~/.openclaw/logs/ with timestamps and all output. The timestamp file at ~/.openclaw/.update-timestamp records status, version, and date — useful for other monitoring scripts to detect stale state.
